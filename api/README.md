# Task Manager API

NestJS API for the Section 1 Task Manager.

## Development

```bash
npm install
npm run start:dev
```

The API listens on `http://localhost:3001` by default. Set `PORT` to override
the port or `WEB_ORIGIN` to change the allowed frontend origin.

## Verification

```bash
npm test
npm run test:e2e
npm run build
npm run lint
```
